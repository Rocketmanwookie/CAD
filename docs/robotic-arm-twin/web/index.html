🛑 Think before you test

Set Joint 1 to 0°. Think about how Joint 2’s gravity deflection at −90° should relate to its deflection at +90°. Recall that, for the same downward force, torque depends on the lateral distance from the fulcrum to the force’s line of action. Make a prediction, then test both positions.

How the static gravity estimate works

Let a be the shoulder angle and b = a + elbow angle. Horizontal payload offsets are x₁ = L₁ cos(a) + L₂ cos(b) from the shoulder and x₂ = L₂ cos(b) from the elbow. Gravity acts downward, so its signed torque is τᵍ = −mgx. The table shows the opposite holding torque, +mgx, needed to balance it. Small passive sag is Δq = τᵍ/k in radians; multiply by 180/π for degrees. Negative means clockwise. This first-order estimate neglects link mass, controller compensation, and changes in load moment as the joints deflect. It is not predicted error for a servo-controlled ABB robot.
