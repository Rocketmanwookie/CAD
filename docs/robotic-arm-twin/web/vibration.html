Model parameters and assumptions

Editable starting values are examples, not ABB specifications. Gear ratio G = motor speed / load speed. Motor inertia is reflected to the output as Jₘ = G²Jᵣ. Torque input, damping, shaft stiffness, and effective holding stiffness are all expressed on the output side. Holding stiffness is a simplified support/servo approximation, not ABB controller software.

Equations, interpretation, and source

With output-equivalent motor angle qₘ and load angle qₗ, the model is:

Jₘq̈ₘ + bₘq̇ₘ + kₚqₘ + kₛ(qₘ − qₗ) + cₛ(q̇ₘ − q̇ₗ) = τ(t)

Jₗq̈ₗ + bₗq̇ₗ + kₛ(qₗ − qₘ) + cₛ(q̇ₗ − q̇ₘ) = 0

Time response uses fourth-order Runge–Kutta with a step selected from the fastest natural/excitation frequency. Frequency response solves (K − ω²M + iωC)Q = [1, 0]ᵀ. Natural frequencies solve det(K − ω²M) = 0. The frequency response always uses unit torque, independent of the selected time-response amplitude.

Periodic input is τ = A sin(2πft), starting from rest. Ring-down has zero applied torque and starts with the selected motor-side displacement while the load starts at zero. The last-half RMS is a finite-record statistic; it is not guaranteed steady state. The model is linearized about equilibrium and excludes gravity-stiffness changes, backlash, bearing defects, electrical dynamics, and the actual feedback controller.

Standard vibration background: MIT OpenCourseWare — frequency response and practical resonance. These model parameters are independent assumptions, not taken from the ABB manual or CAD. To use this in the digital twin, identify inertias, stiffnesses, damping and excitation from documented engineering data and synchronized joint/motor measurements, then validate predictions on a separate recording.
