# Architecture decision records

Create one ADR for a durable architectural decision that changes a public
contract, dependency boundary, persistence format, or ownership boundary.

Use `NNNN-short-title.md` and include: context, decision, alternatives,
consequences, evidence/links, status, and any required migration plan. ADRs
record decisions; they do not replace the operations ledger or release gate.
