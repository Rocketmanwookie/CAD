# Changelog

All notable changes to IntegraCAB Open will be documented in this file.

This project follows Semantic Versioning once public APIs stabilize. During `0.y.z`, APIs, XML schemas, and generated output formats may change.

## [0.1.0-dev] - 2026-06-24

### Changed

- Renamed the original seed from the historical working title `ControlForgeCAD` to `IntegraCAB Open`.
- Renamed the Python package from `controls_wb` to `integracab`.
- Updated the FreeCAD workbench/menu label to `Controls / Automation`.
- Updated package metadata name to `IntegraCABOpen`.
- Updated documentation to define IntegraCAB Open as an integration-first controls-engineering orchestration layer.

### Added

- Master TODO and roadmap.
- Integration-first policy.
- Controls engineering learning path.
- Intake matrix.
- Companion workbench roadmap for HMI and digital twin concepts.
- Standards/resource map.
- Stakeholder request templates.
- Project intake JSON schema seed.

### Known limitations

- Workbench commands are architecture stubs, not production FreeCAD tools yet.
- XML mappings are illustrative and not full certified exports.
- Safety validation is structural only; it does not certify PL, SIL, or category compliance.
