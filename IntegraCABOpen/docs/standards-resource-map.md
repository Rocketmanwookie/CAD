# Standards and Resource Map

This file lists standards, formats, and resource families that IntegraCAB Open should point to or integrate with. It is not a substitute for purchased standards, official documentation, or vendor manuals.

## Resource families

- FreeCAD core documentation and workbench/addon packaging guidance.
- FreeCAD BIM/openBIM workflows.
- FreeCAD Spreadsheet, TechDraw, and BOM-related workbenches.
- CADbase or equivalent reusable CAD/component library tooling.
- IEC 61131-3 and PLCopen XML.
- AutomationML / CAEX.
- OPC UA and OPC UA NodeSet2 XML.
- IFC / ifcXML, COBie, and BCF.
- ETIM, ECLASS, and IEC Common Data Dictionary.
- ISA-101 / HMI guidance.
- ISA/IEC 62443 industrial cybersecurity concepts.
- NEC / NFPA 70, NFPA 79, UL 508A, IEC 60204-1, ISO 13849, IEC 62061, IEC 61508.

## Repository policy

- Link to official resources where possible.
- Do not copy restricted standards text.
- Do not commit proprietary vendor manuals or CAD files unless redistribution rights are explicit.
