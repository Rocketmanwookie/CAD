# Controls document package

This directory contains the source package supplied for IntegraCAD Open's
future engineering-document workflow. It is a set of reusable templates and
reference assets, not a completed project delivery and not a claim of
regulatory, safety, code, or manufacturer approval.

The governing product design basis is
[`docs/governance/INTEGRACAD_OPEN_SCOPE.md`](../../../docs/governance/INTEGRACAD_OPEN_SCOPE.md).

## Known omission

The scope requires an SAT — Site Acceptance Test Protocol. The supplied
package does not contain one. It must be added from a reviewed source before
it can be offered as a workbench template or release deliverable.

## Usage boundary

The Markdown and CSV files are editable source templates. The PDF and DXF
files are retained as reference assets; they are not regenerated by the
current workbench. Preserve source provenance and obtain the appropriate
engineering review before using a generated or edited document for a live
project.
