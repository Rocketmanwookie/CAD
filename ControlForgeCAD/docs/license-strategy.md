# License Strategy

## Selected default: MIT

The initial project seed uses the MIT License for original code, documentation, XML schemas, and examples.

Reasoning:

- It is permissive and simple.
- It allows commercial and private use.
- It has low friction for manufacturers, panel shops, controls engineers, and integrators.
- It requires preservation of copyright and license notices.

## Practical split

| Asset | Recommended license |
|---|---|
| Original Python workbench code | MIT |
| XML schemas | MIT or CC0 |
| Documentation | CC BY 4.0 or MIT |
| Example projects | MIT |
| Manufacturer catalog data | Do not include unless redistribution rights are clear |
| FreeCAD logo/assets | Do not bundle unless allowed by upstream terms |

## Practical rule

Do not copy vendor catalog files, manufacturer CAD models, proprietary PLC export examples, or third-party icons into the repository unless the redistribution license is explicit.
