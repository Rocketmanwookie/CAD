# Standards and Resource Map

This file lists standards, formats, and resource families that IntegraCAB Open should point to or integrate with. It is not a substitute for purchased standards, official documentation, or vendor manuals.

## FreeCAD and open-source CAD resources

- FreeCAD core documentation and developer handbook.
- FreeCAD workbench/addon packaging guidance.
- FreeCAD BIM/openBIM workflows.
- FreeCAD Spreadsheet, TechDraw, and BOM-related workbenches.
- CADbase or equivalent reusable CAD/component library tooling.

## PLC and control logic

- IEC 61131-3 for PLC programming language concepts.
- PLCopen XML for IEC project/logic exchange.
- Vendor PLC IDEs for actual deployment.
- OpenPLC/Beremiz/CODESYS-style references where useful and license-compatible.

## Automation system exchange

- AutomationML / CAEX for automation topology.
- COLLADA references through AutomationML for geometry/kinematics when useful.
- PLCopen XML references through AutomationML for logic.

## Runtime information models

- OPC UA.
- OPC UA NodeSet2 XML.
- Tag dictionaries.
- Historian/tag export formats.

## BIM / openBIM

- IFC / ifcXML for BIM/facility context.
- COBie for asset handoff.
- BCF for issue coordination.
- IDS for information delivery requirements where practical.

## Product classification and component metadata

- ETIM.
- ECLASS.
- IEC Common Data Dictionary.
- Manufacturer official CAD/datasheet portals.
- Distributor catalogs only when terms and accuracy are acceptable.

## HMI / SCADA

- ISA-101 / HMI guidance.
- High-performance HMI concepts.
- Alarm philosophy and alarm rationalization references.
- Vendor-specific HMI platforms only through future adapters.

## Industrial cybersecurity

- ISA/IEC 62443 family.
- IT/OT segmentation, zones, conduits, remote access, backup, account control, and patching concepts.

## Electrical, panel, and machine references

- NEC / NFPA 70.
- NFPA 79.
- UL 508A.
- IEC 60204-1.
- ISO 13849.
- IEC 62061.
- IEC 61508.

## Digital twin and simulation

- AutomationML.
- OPC UA.
- FMI/FMU.
- ROS 2.
- Gazebo / Ignition.
- Discrete-event simulation references.

## Repository policy

- Link to official resources where possible.
- Do not copy restricted standards text.
- Do not commit proprietary vendor manuals or CAD files unless redistribution rights are explicit.
- Use examples with fictional or openly licensed data.
