# Controls Engineering Glossary

This glossary is a starter reference for new controls engineers. It should favor short practical definitions and links to official resources where possible.

## Core terms

| Term | Meaning |
|---|---|
| AHJ | Authority Having Jurisdiction; the organization or official responsible for approving compliance in a location or application. |
| BOM | Bill of materials; list of parts/materials required for a build. IntegraCAB should feed BOM tools, not replace them. |
| BCF | BIM Collaboration Format; model coordination and issue exchange format. |
| BIM | Building Information Modeling; structured facility/building model and process. |
| CADbase | Proposed or external local CAD/component library for reusable models, datasheets, and part metadata. |
| CEProject | IntegraCAB internal XML project format. |
| COBie | Construction Operations Building Information Exchange; asset/handover information. |
| DIN rail | Standardized rail used to mount industrial control components inside panels. |
| EDM | External Device Monitoring; feedback monitoring used in safety circuits. |
| HMI | Human-Machine Interface; operator interface for machine/process control. |
| I/O | Input/Output; field signals connected to PLC/controller channels. |
| IFC | Industry Foundation Classes; openBIM building/facility data model. |
| MCR | Master Control Relay; relay architecture historically used to remove/control power to outputs. |
| OPC UA | Open Platform Communications Unified Architecture; industrial interoperability and information modeling standard. |
| PLC | Programmable Logic Controller; industrial controller for machine/process automation. |
| PLCopen XML | XML exchange format associated with IEC 61131-3 PLC project/logic data. |
| SCCR | Short-Circuit Current Rating; maximum short-circuit current an assembly can withstand under defined conditions. |
| SCADA | Supervisory Control and Data Acquisition; supervisory monitoring/control system. |
| STO | Safe Torque Off; drive safety function that removes torque-producing power. |
| VFD | Variable Frequency Drive; motor drive that controls AC motor speed/torque. |
